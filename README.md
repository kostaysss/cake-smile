# cake.smile 🧁

Лендинг домашней кондитерской **cake.smile** — торты, капкейки, макаруны и десерты на заказ.

Отдельный самостоятельный проект (не связан со Skill Forge).

## Стек

- Чистый HTML / CSS / JavaScript, без сборки и зависимостей
- Шрифты Google Fonts (Comfortaa, Manrope)

## Структура

```
cake-smile/
├─ index.html   — разметка страницы
├─ styles.css   — стили и адаптив
├─ script.js    — меню, мобильное меню, форма заказа
├─ assets/      — картинки (по мере добавления)
└─ README.md
```

## Как открыть

Просто откройте `index.html` в браузере. Либо запустите локальный сервер:

```bash
python -m http.server 8080
```

и откройте http://localhost:8080

## Разделы

- Hero с призывом к заказу
- Меню (генерируется из данных в `script.js`)
- Галерея работ
- О нас
- Отзывы
- Форма заказа (демо, без бэкенда)
- Футер с контактами
